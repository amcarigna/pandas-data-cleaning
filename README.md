# Cleaning a Dataset with Pandas
In this project, I cleaned up a small dataset containing a list of pokemon and their attributes. The `.csv` file had many mistakes and errors to be cleaned, including:
- bad data types (strings in numeric columns and vice versa)
- duplicate data
- missing data
- bad data formatting (e.g., wrong case or bad punctuation)
- typos
- hanging whitespace
Then I saved the cleaned up dataset to a new `.csv` file.  
In order to do this, I also created functions to search the dataframe a little more easily, and a function to move rows around to preserve the order of the pokemon after deletions.
